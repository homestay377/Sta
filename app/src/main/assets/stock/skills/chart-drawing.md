# 在 K 线图上绘图

你有一个工具 `draw_on_chart`，可以在用户当前看的图上画东西。用户看得见你画的一切，
所以**画错比不画更糟**：一条画歪的趋势线会直接误导他的判断。

## 一、动手前先取数

**绝对不要自己编日期。** 先调 `get_kline` 拿到真实的 K 线数组，从返回结果里挑日期。

图上画的每个点都必须来自真实数据：

- 趋势线的端点 → 用真实的**波段高点/低点**，不要用收盘价凑
- 中枢的上下边界 → 用缠论算出来的 `zg` / `zd`（调 `analyze_chan` 取）
- 支撑压力 → 用真实成交密集区或前高前低

如果你没有取数就画，日期对不上会被工具拒绝，白跑一趟。

## 二、坐标怎么写

### 时间（x）

三种写法，任选：

| 写法 | 例子 | 说明 |
|---|---|---|
| 完整日期 | `"2026-07-27"` | 最稳，优先用这个 |
| 省略年份 | `"07-27"` | 方便，但跨年时会有歧义 |
| 索引 | `12` | 0 起；`-1` = 最后一根；`last` / `first` |

**优先用完整日期。** 索引会随数据长度变化，日期不会。

### 价格（y）

正数。用真实价格，不要用百分比或相对值。

## 三、图元怎么选

| 你要表达 | 用哪个 | 必填参数 |
|---|---|---|
| 某个价位（支撑/压力） | `hline` | `price` |
| 两点连成的趋势线 | `trendline` | `x1,y1,x2,y2` |
| 从一点向右延伸的线 | `ray` | `x1,y1,x2,y2` |
| 一段区间（中枢/箱体/缺口） | `rect` | `x1,y1,x2,y2` + `fill:true` |
| 方向（涨到哪、跌到哪） | `arrow` | `x1,y1,x2,y2` |
| 图上写字 | `text` | `x,y,text` |
| 标记某个点（买卖点） | `dot` | `x,y` |

### 常用组合

**下降趋势线**（连接两个高点）：

```json
{"type":"trendline","x1":"2026-07-21","y1":12.40,"x2":"2026-07-30","y2":11.85,"color":"down","label":"下降趋势线"}
```

**中枢框**（用缠论的 zg/zd）：

```json
{"type":"rect","x1":"2026-07-22","y1":11.20,"x2":"2026-07-29","y2":10.60,"fill":true,"color":"target","label":"中枢"}
```

**三买标注**：

```json
[
  {"type":"dot","x":"2026-07-28","y":11.25,"color":"up","size":5},
  {"type":"text","x":"2026-07-28","y":11.45,"text":"三买","color":"up"}
]
```

**支撑压力双线**：

```json
[
  {"type":"hline","price":10.60,"color":"support","label":"支撑 10.60"},
  {"type":"hline","price":12.40,"color":"resist","label":"压力 12.40"}
]
```

## 四、颜色

| 键 | 用于 |
|---|---|
| `support` | 支撑、买点 |
| `resist` | 压力、卖点 |
| `stop` | 止损 |
| `target` | 目标、中枢框 |
| `up` | 上涨方向、看多标记 |
| `down` | 下跌方向、看空标记 |
| `accent` | 需要突出但不属于以上语义时 |

不填就跟随主题文字色。

## 五、三种模式

- `replace`（默认）—— 替换之前画的。**一次画完用这个**，避免叠加。
- `append` —— 在已有基础上追加。只在用户要求"再加一条"时用。
- `clear` —— 清空全部。用户说"清掉""擦掉"时用。

**一次画完**：把要画的全部放进同一个 `shapes` 数组，用 `replace`。
分多次调用容易画出重复图形。

## 六、会被拒绝的情况（看到报错必须改）

工具会逐条校验，非法的整条丢弃，并把原因返回给你。**不要忽略返回的报错**，
按提示修正后重画：

| 报错 | 原因 | 怎么改 |
|---|---|---|
| `找不到时间为「X」的 K 线` | 日期不在数据里 | 从 `get_kline` 返回里挑真实日期 |
| `索引 N 超出范围` | 索引越界 | 用 `0 ~ 长度-1`，或 `-1` 表示最后一根 |
| `缺少 x2` 之类 | 参数不全 | 补齐该图元的必填参数 |
| `必须是正数` | 价格给了负数或 0 | 用真实价格 |
| `不支持的图元类型` | 类型拼错 | 只能从上面 7 种里选 |

## 七、几条硬规矩

1. **先取数，再画。** 没取数就画 = 编造日期 = 一定失败。
2. **一条趋势线只连两个真实波段点。** 不要用"大概"的价格。
3. **别画太多。** 一次最多 5~6 个图元。画满一屏等于什么都没说。
4. **画完要用文字解释。** 图上一条线，对话里要说明"这条线是从哪连到哪、代表什么"。
5. **不画你算不出来的东西。** 数据不够就说"数据不足，无法画"，不要硬凑。
6. **不要改变用户看到的股票和周期。** 只在当前图上画。

## 八、画完的回执

工具会返回类似：

```
已在图上画了 3 个图元：trendline、rect、text
以下 1 条未画上（请修正后重试）：
第 2 条：x2：找不到时间为「2026-13-45」的 K 线。可用范围：2026-07-20 ~ 2026-08-28
```

看到"未画上"，就按给出的范围改掉那个坐标，再调一次（用 `append` 只补画失败的那条，
或用 `replace` 全部重画）。
