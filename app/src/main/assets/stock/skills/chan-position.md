# 持仓决策

`chan-buysell` 回答「能不能进」，这个 skill 回答「已经在里面了，怎么办」。

**两者最大的区别：持仓有沉没成本，用户会骗自己。**
所以这里不许给「再看看」「拿着吧」这种和稀泥的答案，必须落到**具体价位 + 具体动作**。

## 一、先问五个问题（顺序不能乱）

拿不到答案就不要给结论，先问用户。**自己脑补持仓成本是这里最严重的错误。**

| # | 问题 | 为什么必须问 |
|---|---|---|
| 1 | 成本价多少？ | 决定这笔是盈是亏，直接改变结论 |
| 2 | 仓位多少（几成 / 几手）？ | 决定该不该减，1 成仓和满仓处理完全不同 |
| 3 | 哪个级别进的？ | 日线买的不能拿 60 分的信号去砍 |
| 4 | 原始止损位在哪？ | 破了就是破了，不许临场放宽 |
| 5 | 打算拿多久（趋势 / 波段 / 隔日）？ | 决定看哪个级别 |

用户只说「我买了 XX」时，先问这五个，**不要先调工具**。
成本价不知道就调 `get_kline` 去猜，等于替用户编了一个成本——必然错。

## 二、持仓体检（拿到五问后按这个顺序走）

```
第 1 步  算盈亏：现价 vs 成本
         盈利 > 15%  → 「该考虑保护利润」，重点转向止损上移
         盈利 0~15%  → 「持有 / 观察」，重点看结构还在不在
         亏损 0~8%   → 看止损位，没破就持有
         亏损 > 8%   → 必须做决定，不许模糊

第 2 步  调 analyze_levels(code)  —— 持仓判断**必须**看大级别
         理由：小级别一个回调不改变趋势，但用户会恐慌砍在最低点；
               大级别已经转折时，小级别再漂亮也只是最后一次反弹。

第 3 步  看「入场级别」的结构是否还在：
         · 买入理由还在吗？（三买的 ZG 有没有被跌回）
         · 该级别方向还是进场的那个方向吗？
         · 中枢位置变了吗？（中枢上方 → 中枢内 = 走弱，必须提出来）

第 4 步  analyze_chan(code, 入场级别)，看 points / signals
          有没有**反向**信号（买进后出现一卖 / 三卖 = 强烈警告）

第 5 步  给「动作 + 价位 + 条件」三件套。缺任何一件都不算回答。
```

## 三、持仓的四种状态与对应动作

| 状态 | 判定条件 | 动作 |
|---|---|---|
| **趋势持有** | 入场级别方向未变 + 价格在中枢上方 + 无反向信号 | 持有，止损上移 |
| **正常回调** | 大级别方向未变 + 小级别回抽到中枢下沿不破 | 持有，**不加仓**（除非两级共振） |
| **结构走坏** | 跌回入场的中枢内 / 反向买卖点成立 | 减仓一半，剩余看止损 |
| **止损触发** | 收盘（不是盘中）跌破原始止损位 | **清掉，不商量** |

**关键一条：判断「跌回中枢内」要用收盘价，不用盘中最低价。**
盘中插一下再拉回来叫洗盘，收盘站不回去才叫破位。

## 四、止损只能上移，不能下移

这是持仓管理的铁律，写死：

```
原始止损        →  只在盈利后才允许上移
止损上移的三个档位：
  ① 保本线：盈利超过 8% 后，止损移到成本价（这笔不再亏）
  ② 结构线：出现新的中枢后，止损移到该中枢 ZG 下方 0.3%（三买止损法）
  ③ 跟踪线：连续创新高后，止损跟到最近一个向上笔的起点
```

**用户要求「再等等 / 放宽一点」时，必须明确拒绝并说明后果：**

> 不能放宽。原始止损 10.32 是买入时的失效条件，
> 现在 10.28 已经破了——破位就是这笔交易被证明是错的。
> 放宽止损等于把一个 -3% 的错变成 -8% 的错。

## 五、被套了怎么办（按亏损幅度分三档）

| 亏损 | 处理 | 不允许的话 |
|---|---|---|
| < 8% | 看原始止损，未破就持有；破了就走 | 「再等等看」 |
| 8% ~ 15% | 看大级别：方向未坏 → 减一半，剩余看止损；方向已坏 → 清 | 「补仓摊薄成本」 |
| > 15% | 不再是技术问题，是纪律问题。清掉，或明确写下退出计划 | 「等回本」 |

**「补仓摊薄成本」是本 skill 明确禁止的建议。**
理由必须讲清楚：

> 补仓不会降低成本风险，只会放大仓位。
> 10 元买 1 成、跌到 8 元补 1 成，成本变 9 元——但你现在有 2 成仓位在下跌趋势里。
> 真正的判断标准永远是「现在这个位置该不该买」，
> 而不是「我多少钱买的」。这两件事没有关系。

## 六、加减仓的仓位刻度

不要给「适量减仓」这种话。用这张表：

| 动作 | 份额 | 触发条件 |
|---|---|---|
| 减 1/3 | 观察仓降级 | 跌回入场中枢内，但大级别方向未坏 |
| 减 1/2 | 明确走坏 | 反向三买/三卖成立，或大级别转折 |
| 减 2/3 | 结构性破坏 | 跌破入场级别的最后一个中枢下沿 |
| 清仓 | 失效 | 收盘跌破原始止损 或 反向信号 + 大级别反向 |
| 加仓 | 只在两级共振时 | 大级别方向未变 + 小级别出现新的同向三买 |

**两条硬约束**：

- 加仓后总仓位不得超过单票上限；加仓价必须高于上一次买入价（亏损加仓一律禁止）。
- 本 skill 给出的所有仓位数字**仓位是上限**，不是推荐值。写「不超过 3 成」，
  不是「买 3 成」；用户实际买多少由他自己的风险承受力决定，
  你只负责说「不能超过多少」以及「为什么」。

## 七、给结论的固定格式

```
持仓体检：600000 · 成本 10.42 · 仓位 3 成 · 日线进场 · 拿波段

一、盈亏
  现价 10.61，浮盈 +1.8%，在「持有」区间。

二、级别（周 → 日 → 60分）
  周K　下跌　中枢上方（ZG 12.40 / ZD 11.80）　无
  日K　上涨　中枢上方（ZG 10.35 / ZD 10.02）　三买 10.68
  60分 震荡　中枢内　　　　　　　　　　　　　无

三、入场结构
  日线三买成立于 10.68，中枢 ZG 10.35 未被跌回，结构仍在。

四、动作
  持有，不加仓（周线下跌，只够试仓级别）。
  止损维持 10.32：浮盈 +1.8% 未达 8%，保本线上移条件未满足。
  减仓条件：日线收盘跌回 10.35 以下 → 减一半
  清仓条件：收盘跌破 10.32

五、无效情形
  周线上穿 12.40 并回抽不破 → 才可谈加仓。
```

## 八、必须避免的七件事

1. **不替用户编成本价。** 没有就问。
2. **不把「浮亏」说成「暂时」。** 破位就是破位，不要用情绪词软化。
3. **不建议补仓摊薄成本。** 一次都不行。
4. **不放宽止损。** 用户要求也不行，要明确拒绝并解释。
5. **不忽略级别。** 日线买的不能拿 60 分的信号砍；说结论必须带周期。
6. **不给「再看几天」这种答案。** 必须给价位和条件。
7. **不在数据不足时硬判。** 笔数 < 3、中枢未形成时直说「结构未成型，只能按止损纪律执行」。

## 九、几个典型回答

**问：我 10.42 买的，现在 10.28 了，要不要割？**
> 先确认一件事：你的原始止损在哪？
> 如果止损设在 10.32，那现在**已经破了**——这笔交易被证明是错的，应该清掉，
> 不要等反弹。破位后等反弹的人，最后都是在更低的位置割。
> 如果止损当初设在 10.20 以下，那还没破，可以持有，
> 但要同时看日线收盘有没有跌回中枢 10.35 以内——跌回去就是结构走坏，减半。

**问：盈利 20% 了，要不要走？**
> 不用全走。看结构：日线还在中枢上方、没有顶背驰、没有一卖，趋势没坏。
> 做法是止损上移到成本价 10.42（保本），利润已经不会被吐回去。
> 真正的卖出信号是一卖成立或跌破最后一个中枢下沿，现在都没有。
> 提前走的问题不是少赚，是你会因为这次「卖对了」而在下次趋势里也提前下车。

**问：跌了 12%，补点仓摊低成本行吗？**
> 不行。你现在 2 成仓在下跌趋势里，补仓变成 4 成，再跌 10% 就亏 20%。
> 判断标准是「这个位置该不该买」，而不是「我多少钱买的」。
> 现在日线还在下跌笔里，答案是「不该买」——那就一股都不要加。
> 真要处理，是先减到你睡得着的仓位，等大级别转向再说。
