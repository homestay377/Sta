# 基本面分析

技术面管「什么时候」，这个 skill 管「值不值得买」。

**先说最难听的一句：基本面分析最容易变成「编故事」。**
看到一个 ROE 就断言「优秀」，看到一个低 PE 就说「便宜」，都是在骗人。
下面每一节都在防这件事。

## 〇、数据边界（先看这个，别越界）

工具**能拿到**的，全部来自真实接口：

- 估值：现价、涨跌幅、市盈率、市净率、总市值、流通市值
- 财报：营业总收入、营业成本、归母净利润、扣非净利润、总资产、净资产、总负债
- 由报表**算出**的：毛利率、净利率、资产负债率、ROE
- **同比增速**：营收、归母净利、扣非（工具已按去年同报告期对齐）
- 资金面：龙虎榜（日期、涨跌、成交额、占成交额比、机构席位说明）

工具**拿不到**的，说明为什么替代不了：

- 研发投入、分红方案、股东明细、一致预期
- 银行/保险的不良率、净息差；ETF 的跟踪误差、规模、成分股集中度
- 公告原文、新闻、舆情

> 这些字段在工具输出里**根本不会出现**。看到「营收增速」这类问题，
> 就回答「当前工具不提供营收增速数据，无法判断」，而不是用净利润增速去顶替，
> 更不要编一个数字。拿不到数据时的诚实，比给一个看似专业的答案重要得多。

ROE 是**报告期累计值，未经年化**：三季报的 ROE 是前三季度口径，和年报的 ROE 不可直接比较，
需要年化时自己乘 4/3 并明确说明这是估算。

## 一、取数（不许凭印象）

- 单只：`get_fundamental(code)` → 估值快照 + 最近 4 期财报
- 比较：`compare_fundamental(codes)` → 2~4 只同口径横向对比

**必须先调工具，再下结论。** 你没有任何一只股票的真实财务数据是靠记忆知道的。

ETF / 指数没有财报，`reports` 会为空 —— 这时直说「ETF 无财报，只能看估值与跟踪标的」，
不要去分析成分股的财务然后假装是它的。

## 二、估值判断：只能定档，不能定买卖

| 指标 | 怎么读 | 陷阱 |
|---|---|---|
| 市盈率 PE | 回本年限的粗略估计 | **银行/地产/煤炭天然 5~8 倍，不叫便宜**；亏损股显示为负/无 |
| 市盈率 TTM | 滚动四季，比静态 PE 准 | 周期股高点时 TTM 最低（越贵越好看） |
| 市净率 PB | 相对净资产的溢价 | **轻资产公司（软件/传媒）PB 天然高，不叫贵** |
| 总市值 | 判断盘子大小 | 小市值不等于容易涨 |

**判断顺序（必须按这个顺序说）：**

```
第 1 步  先说行业属性 —— 银行/保险/地产 / 周期（煤钢有色化工）/ 消费 / 科技成长
         没搞清行业就说「PE 低=便宜」是外行话。

第 2 步  再看估值在同行业里的位置（工具给不了分位数，就明说「缺行业分位数据」）

第 3 步  最后才给档位：偏低 / 合理 / 偏高 / 无法判断

第 4 步  明确写「估值只能定档，不构成买卖依据，买点看技术面」
```

## 三、财务只看四件事（其余都是噪音）

1. **ROE（净资产收益率）** —— 最核心。
   - 连续 4 期稳定 > 15%：优秀
   - 10%~15%：合格
   - < 8%：资本回报偏弱
   - **必须看是「连续」还是「单期跳高」**，单期高可能是卖资产
2. **净利润趋势** —— 涨还是在跌。工具给的是累计数（三季报是前三季合计），
   **不同报告期之间的数字不能直接比**，要比就跟去年同期比（工具目前没给去年同期，
   那就明说「缺去年同期数据，无法算同比」）。
3. **营收趋势** —— 净利涨但营收不涨 = 靠省钱或非经常损益，质量差。
4. **净利率** —— 毛利率缺失时看净利率；净利率骤降要警惕。

**不要做的事**：不要把 EPS 从 0.52 → 0.89 → 1.17 说成「同比大增 125%」。
那是三个季度累计值，不是同比增长。这是本 skill 明确禁止的算法错误。

## 四、行业差异（最容易翻车的地方）

| 行业 | 该看什么 | 不该看什么 |
|---|---|---|
| 银行/保险 | PB、不良率、净息差 | PE（天然低，没有意义）、毛利率 |
| 周期股（煤钢有色化工） | PB、产能、商品价格位置 | PE（盈利高点时 PE 最低，是顶不是底） |
| 消费 | PE、ROE、毛利率稳定性 | PB |
| 科技成长 | 营收增速、研发投入 | PE（可能长期很高或为负） |
| ETF/指数 | 跟踪误差、规模、成分股集中度 | 财报、ROE |

**ETF 特别注意**：ETF 没有「市盈率」这个公司层面的概念，
工具返回的 PE/PB 是**指数加权**值，只能说「跟踪标的整体估值」，不能说「这只基金的估值」。

## 五、标准作业流程

```
第 1 步  确认标的类型：个股 / ETF / 指数（ETF 代码 51/56/58 开头，可直接判断）
第 2 步  调 get_fundamental，把数据拿到手
第 3 步  判行业属性（工具不给行业名的话，用名称/代码常识判断，并注明「据名称判断」）
第 4 步  按第二节四步走，给估值档位
第 5 步  财务按第三节四件事逐条说，缺数据就写缺
第 6 步  结论必须写清「估值档位 + 财务质量 + 数据缺口 + 不构成买卖建议」
```

## 六、给结论的固定格式

```
基本面：浦发银行（sh600000）

一、类型与行业
  个股，银行。银行看 PB 与资产质量，PE 天然偏低，不作便宜依据。

二、估值
  现价 10.40　PE 6.40　PE(TTM) 5.20　PB 0.46
  总市值 3463.8 亿
  档位：PB 0.46 属于破净，银行板块内偏低；但缺行业分位数据，无法精确排序。

三、财务（最近 4 期）
  2026-09-30　营收 1381.33 亿　净利 405.72 亿　ROE 5.20%　净利率 29.77%
  2026-06-30　营收 937.77 亿　净利 309.51 亿　ROE 3.96%　净利率 33.43%
  （累计数，逐期递增属正常，不能当同比）
  ROE 5.20% 是三季报累计值，年化约 6.9%，在银行里属中下水平。
  净利率 29.77% 较上期 33.43% 下降，需关注。

四、结论
  估值低（破净）+ 盈利能力中等 → 属于「便宜但有原因」的典型。
  便宜的原因是市场担心资产质量，不是市场犯错。
  数据缺口：缺不良率、缺去年同期、缺行业分位。
  这只能说明「估值不贵」，不构成买入建议，买点仍看技术面。
```

## 七、必须避免的七件事

1. **不调工具就谈财务。** 背出来的数字基本都是错的。
2. **不把累计季报当同比。** EPS 0.52→1.17 是三季累计，不是增长 125%。
3. **不用单一指标下结论。** 只看 PE 或只看 ROE 都会错。
4. **不跨行业比 PE。** 银行 6 倍和软件 60 倍不能排序论贵贱。
5. **不给「目标价」。** 你算不出来，编一个就是害人。
6. **不说「所以可以买」。** 基本面回答「值不值」，技术面回答「什么时候」。
7. **缺数据就说缺。** 「无行业分位」「无去年同期」写出来，比编一个数强一百倍。
