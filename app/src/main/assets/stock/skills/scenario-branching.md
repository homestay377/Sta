# 反事实推演

描述现状回答的是"现在是什么"；做决策需要的是"如果发生 X，我该怎么办"。后者叫分支推演——**它是把结构分析变成可执行计划的那一步**。

## 一、为什么这事值得单独做

`analyze_chan` 返回的是快照：当前在中枢下方、ZG 12.35、ZD 11.80、有个底背驰。这些是事实，但用户拿着它们**还是不知道明天该干什么**。

真正有用的是：

> 如果站回 12.35（ZG），中枢内的下跌就算走完，那时才是能考虑的位置；
> 如果继续跌破 11.80（ZD）且背驰失效，说明下跌延续，原来的"见底"判断错了。

同样一组数据，换成分支，就从"描述"变成了"计划"。**市场怎么走你决定不了，但每种情况下你做什么，可以提前想好**——这就是推演的价值。

## 二、从现有字段找关键价位

推演不需要新数据，工具已经给齐了：

| 字段 | 在推演里的作用 |
|---|---|
| 最近中枢的 ZG / ZD | 最天然的两条分界线：站上 ZG、跌破 ZD |
| 当前价相对中枢的位置 | 决定现在处在哪个分支里 |
| 最近笔的 toPrice（高低点） | 前高/前低，是"创新高/新低"的判据 |
| 背驰的 price | 衰竭点，跌破它通常意味着背驰失效 |
| 建议里的止损位 | 已有的失效线，直接拿来当分支边界 |

选分支位的原则：**用结构位，不用整数关口或心理价位**。12.35 是 ZG 才有意义；"12 块整数关"没有结构依据。

## 三、一个分支该有的四件事

每个分支不必长，但四件事决定它有没有用：

1. **触发条件**：什么价位/什么信号成立（要可观测，不能是"如果情绪转好"）
2. **结构含义**：这个条件成立，说明原来的判断发生了什么变化
3. **对应动作**：那时该做什么（进/加/减/观望）
4. **失效点**：这个分支本身在什么情况下被推翻

缺第 4 条的推演最容易坑人——它只说了"如果涨了怎么办"，没说"如果我判断错了怎么办"。

## 四、分支数量与取舍

不是越多越好。**围绕一到两个关键价位，各给正反两个分支**，通常就够了。

一个自然的取舍方式：

- 挑**离现价最近**的那个结构位（通常是 ZG 或 ZD）
- 给"站上它"和"跌破它"两个分支
- 如果还有第二个关键位（比如背驰点），再补一个"背驰失效"分支

把整张表都列出来，用户读完还是不知道先看哪个。**聚焦离现价最近的决定点**，比列全更有用。

## 五、推演和预测的区别

推演说"如果 A 成立，那么 B 更可能，此时做 C"——它给的是**条件与应对**，不承诺结果。

预测说"明天会涨到 12.5"——它承诺一个结果，而没人能稳定做到这件事。

两者长得很像，区别在于：**推演的每个分支都带失效点，预测没有**。写完后自检：每个分支是不是都能被"如果没按这个走，说明我错了"推翻？不能的话，那多半已经滑向预测了。

## 六、什么时候不太需要推演

- 用户只问"现在什么结构"——描述就够了
- 结构还没成型（笔太少、没有中枢）——没有可靠的价位可拿来分支
- 用户明确只要一个结论、不要一堆"如果"——尊重他要简洁

最后一种值得注意：推演天然会长，把用户烦到不看，就等于没做。他要快速判断时，先给结论，再说"关键位是 X，破/站的话我再细说"。

## 七、几个容易犯的错

1. **每个分支都说"观望"** —— 那不叫推演，叫回避。分支的意义是不同情况有不同动作。
2. **用模糊触发条件** —— "如果企稳""如果情绪好转"无法观测，等于没说。要写成具体价位或具体信号。
3. **忘记当前处在哪个分支** —— 推演完要回到开头说"现在我们在 A 分支里"，否则用户还得自己对号入座。
4. **分支之间不互斥** —— "站上 ZG"和"继续上涨"会同时发生，得是清晰的分界。
5. **把推演当成建议已经成立** —— 推演是预案，不是判断。它成立的前提是触发条件真的出现。
