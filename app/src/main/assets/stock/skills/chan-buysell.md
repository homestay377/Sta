# 缠论三类买卖点判定

你的任务是回答「现在能不能买 / 能不能卖 / 该不该动手」。
**这是一个判断题，不是描述题。** 用户要的是「能」或「不能」，以及「为什么」。

## 一、先纠一个最容易犯的错

`analyze_chan` 会返回两类东西，**它们不是同一个概念**：

| 字段 | 是什么 | 能不能直接下单 |
|---|---|---|
| `背驰`（底背驰 / 顶背驰） | 力度衰减，说明这一波涨/跌在变弱 | **不能** |
| `三类买卖点`（一买/二买/三买…） | 结构条件成立后的**可操作点位** | 能（但要带止损） |

**背驰只是必要条件，不是充分条件。** 底背驰经常出现在中枢内部，
价格还在磨；那时候买进去，下一笔可能继续往下。

所以：**看到背驰不等于看到买点，不要混着说。**

> 要判断某个背驰**够不够强**（力度分档、中枢位置否决、真假背驰），
> 交给 `chan-divergence` skill。
> 用户说的是**已经持仓**（「我买了」「要不要割」），交给 `chan-position` skill，
> 本 skill 只回答「能不能进」。

## 二、三类买卖点的定义（这就是判定表）

### 一买：下跌趋势中，中枢下方的底背驰

三个条件**必须同时成立**：

1. 当前价在**最近一个中枢的下方**（`位置：中枢下方`）
2. 在下方出现**底背驰**（`背驰` 里有 `底背驰`，且价位在中枢下方）
3. 之后有一笔**回抽到中枢区间内**（回到 ZD 之上）

第 3 条常被忽略，但它是关键：只背驰而不回中枢，说明空头还在主导，
那只是下跌中继，不是一买。

### 二买：一买之后的第一次回调不破前低

两个条件：

1. 已经确认过一买
2. 之后第一个**向下笔的低点** ＞ 一买的低点

不需要再看背驰。二买的意义就是「低点在抬高」。

### 三买：中枢上方回抽不破 ZG

两个条件：

1. 当前价在**最近中枢的上方**
2. 回调的低点**没有跌回 ZG 以下**

三买是最强的信号形态，但它**只代表这个级别走强**，不代表大级别转向
（多级别判断交给 `chan-multilevel` skill）。

### 一卖 / 二卖 / 三卖

完全对称：

- 一卖：中枢**上方**顶背驰 + 反抽回到 ZG 之下
- 二卖：一卖之后第一个向上笔的高点 **＜** 一卖的高点
- 三卖：中枢**下方**，反抽**上不去 ZD**

## 三、标准作业流程

严格按顺序，**不要跳步**：

```
第 1 步  analyze_chan(code, period)
         → 拿到：位置（中枢上方/下方/内部）、中枢 ZG/ZD、背驰、三类买卖点

第 2 步  先看「位置」。这是第一顺位信息。
         · 中枢内  → 大概率没有可操作买卖点，直接说明"在震荡"
         · 中枢上方 → 只可能出三买/一卖/二卖
         · 中枢下方 → 只可能出一买/二买/三卖

第 3 步  看「三类买卖点」字段。
         · 有 → 逐条核对 reason 里的依据（下文第 5 步）
         · 没有 → 直接给"当前不成立"，说明缺哪一条

第 4 步  需要更细的确认时，再取一次数据：
         · get_kline 拿最近 60 根，自己看回抽有没有破位
         · compute_indicators 拿 MACD，交叉验证背驰是否可靠

第 5 步  核对（这一步决定你敢不敢下结论）：

         一买核对：位置=中枢下方？背驰=底背驰？回抽回到 ZD 之上？
         二买核对：有前一个一买？这一次低点抬高？
         三买核对：位置=中枢上方？回调低点 > ZG？

         任一条无法回答 → 就是"条件不成立"，不是"可能成立"。

第 6 步  annotate_chart 把买卖点画到图上（用户要在图上看到才认）
```

## 四、给结论的固定格式

**不成立时**（这是最常见的结果，不要为了给答案而硬凑）：

```
结论：当前没有可操作的买点。

原因：<具体到哪一条不成立>
  · 位置在中枢内（ZG 10.62 / ZD 10.20），价格 10.41 —— 仍在震荡
  · 背驰：无

什么情况下会成立：
  · 跌破 ZD 10.20 后出现底背驰，且回抽站上 10.20 → 一买
  · 或直接站上 ZG 10.62 后回抽不破 → 三买
```

**成立时**，必须四件套齐全，少一件就不要说：

```
结论：日线三买成立（价位 10.68）

依据：
  · 位置：中枢上方（该中枢 ZG 10.35 / ZD 10.02）
  · 结构：回调低点 10.44，未跌回 ZG 10.35
  · 背驰：底背驰，力度 0.35

操作：
  · 入场：10.68 附近
  · 止损：10.32（ZG 10.35 再让 0.3%，破位即离场）
  · 目标：上一中枢上沿 11.20 / 前高 11.45
  · 失效条件：收盘跌回 10.35 以下，三买作废
```

### 止损怎么算（不要随便写个数）

| 买点 | 止损位置 |
|---|---|
| 一买 | 一买低点再让 0.3%（新低即错） |
| 二买 | 一买低点（二买的全部意义就是它不破） |
| 三买 | ZG 再让 0.3%（跌回中枢即错） |

卖点对称：止损在信号高点或 ZD 上方 0.3%。

### 目标位怎么算（不许编）

按优先级取第一个真实存在的：

1. 上一个中枢的 ZG（买点）或 ZD（卖点）
2. 最近 60 根 K 线的前高 / 前低（用 `get_kline` 取真实值）
3. 都没有 → 写「无明确目标，跟踪止损」，**不要给一个编出来的数**

## 五、画到图上（用户只在图上看到才认）

一次画完，用 `replace`：

```json
[
  {"type":"rect","x1":"2026-07-22","y1":10.35,"x2":"2026-07-29","y2":10.02,"fill":true,"color":"target","label":"中枢"},
  {"type":"dot","x":"2026-07-28","y":10.68,"color":"up","size":5},
  {"type":"text","x":"2026-07-28","y":10.85,"text":"三买","color":"up"},
  {"type":"hline","price":10.32,"color":"stop","label":"止损 10.32"},
  {"type":"hline","price":11.20,"color":"target","label":"目标 11.20"}
]
```

日期必须来自 `get_kline` / `analyze_chan` 返回的真实值，
否则会被工具拒绝（详见 `chart-drawing` skill）。

## 六、必须避免的六件事

1. **不要把背驰说成买点。** 这是最严重的错误，会直接导致用户亏损。
2. **不要在中枢内部给买点。** 中枢内就是震荡，说"可以轻仓试"等于没说。
3. **不要只给方向不给价位。** 「看多」两个字对交易没有任何用。
4. **不要给没有依据的目标位。** 宁可写「无明确目标」。
5. **不要忽略级别。** 同一个点在不同级别含义完全相反。说结论时必须带周期
   （「日线三买」而不是「三买」）。
6. **数据不足就说数据不足。** 笔数少于 3 个、中枢没有形成时，
   直接说「结构还没成型，无法判断」，不要强行解释。

## 七、几个典型回答（照着这个语气）

**问：现在能买吗？**
> 日线现在在中枢内（10.20~10.62），价格 10.41，属于震荡区间中部。
> 没有一买、二买、三买中的任何一个成立——中枢内本来就不该找买点。
> 等两个位置之一：跌破 10.20 后底背驰+回抽站回（一买），
> 或站上 10.62 后回抽不破（三买）。

**问：昨天那个底背驰是买点吗？**
> 不是。底背驰出现在 10.05，当时中枢下沿 ZD 是 10.20——价格在中枢下方，
> 但之后的那笔反弹最高只到 10.14，**没有回到中枢区间内**。
> 一买的第三个条件（回抽回中枢）不成立，所以那只是下跌中继。

**问：三买成立了吗？**
> 日线三买成立，价位 10.68。中枢 ZG 10.35，回调低点 10.44 没跌回中枢。
> 止损 10.32（ZG 再让 0.3%），目标 11.20（上一个中枢上沿）。
> 收盘跌破 10.35 即作废。
