# 背驰强度分档

背驰只说明「这一波涨/跌在变弱」，**它本身不是买卖点**。
真正要回答的是：这个背驰**够不够强**，强到值不值得动手。

`analyze_chan` 的 `signals[]` 已经给出 `strength` 和 `label`，这个 skill 教你怎么读它们。

## 一、strength 是怎么算出来的（必须知道，否则会误读）

代码里用的是**同向两段的 MACD 柱面积比**（`v10.25` 起与 Python 引擎 `analyze.py` 的
`find_signals` 对齐）：

```js
a1 = Σ 同向 MACD 柱   上一段同向笔（上涨只算红柱、下跌只算绿柱）
a2 = Σ 同向 MACD 柱   当前这段同向笔
strength = 1 - a2 / a1        // 范围通常在 0 ~ 1
成立条件：a1 > 1e-6 且 a2 < a1 * 0.85 且「本段创新高/新低」
特殊：a2 ≈ 0（本段完全没有同向柱）却创新极值 → label 带「极强」，strength = 1.00
```

由此可以推出四条硬事实：

1. **strength 只有 0.15 以上的才算背驰**。因为成立条件是 `a2/a1 < 0.85`，
   即 `1 - a2/a1 > 0.15`。所以看到 `strength = 0.10` 不是「弱背驰」，
   而是**它根本不会出现在 `signals` 里**——看到了一律在 0.15 以上。
2. **`label` 由笔的方向决定**：`dir='down'` 的两段衰减 → `底背驰`（看涨）；
   `dir='up'` → `顶背驰`（看跌）。不要按价格高低去猜。
   括号里是级别：`(趋势)` = 已经有两个以上中枢，`(笔)` = 单笔级别，
   `(极强)` = 本段同向动能归零。
3. **代码已经强制要求「创新极值」**：后一段必须真的创新高/新低才会进 `signals`，
   所以「没创新低却报底背驰」这种情况不会再有。
4. **代码不再比较相邻两笔**，而是比「同向的上一段」（隔一笔）。
   如果你自己拿笔表手工算，记得跳过一个方向相反的笔。

## 二、分档表（这是本 skill 的核心）

| 档位 | strength | 含义 | 该怎么说 |
|---|---|---|---|
| 弱 | 0.15 ~ 0.35 | 勉强够阈值，常见于震荡中的小波动 | 「力度衰减微弱，不足以据此操作」 |
| 中 | 0.35 ~ 0.55 | 力度明显衰减，多数有效背驰落在这里 | 「背驰成立，等结构确认」 |
| 强 | 0.55 ~ 0.75 | 力度衰减过半，可靠性较高 | 「背驰较强，但仍需中枢位置配合」 |
| 极强 | > 0.75（或 label 含「极强」）| 力度只剩四分之一以下 | 「力度衰减极强，反弹/回落概率大」 |

**但这张表只能排「力度」，不能排「能不能买」。** 必须再过第二道关。

### 两条纪律

1. **低于 0.15 的信号不会出现在返回里。** 阈值是 `a2/a1 < 0.85`，
   所以 `strength` 只要出现就一定 > 0.15。
   如果你想说「strength 0.05」「力度只有 5%」——那是你在编，代码根本不会产出这种值。
   `signals` 里没有，就是真的没有，直接说「该级别近期没有背驰信号」。
2. **不许跨股票比 strength。** strength 是同一只股票、同一级别、相邻两笔的**相对比值**，
   A 股 0.60 和 B 股 0.60 之间没有任何可比性。也不要跨级别比。
   永远写成「日线 strength 0.62」，不要单独甩一个数字。

## 三、第二道关：中枢位置（这道关是否决权）

同样的 strength，在不同位置含义完全相反：

| 位置（`stats.boxPosition`） | 背驰含义 | 结论 |
|---|---|---|
| **中枢下方 + 底背驰** | 下跌段衰竭，可能形成一买 | **唯一可操作的方向**（需配合回抽进中枢） |
| **中枢上方 + 顶背驰** | 上涨段衰竭，可能形成一卖 | **唯一可操作的反向方向**（需配合反抽回中枢） |
| **中枢内 + 任何背驰** | 震荡中的内部波动 | **否决。明确说「不算信号」** |
| **中枢上方 + 底背驰** | 上涨中的小回调结束 | 无意义，不要提 |
| **中枢下方 + 顶背驰** | 下跌中的小反弹结束 | 无意义，不要提 |

**第三行是重点：中枢内的背驰一律不算数。**
中枢就是多空反复拉锯的区域，里面的每一次力度衰减都会被下一笔吞掉。
在中枢内喊「底背驰了，可以买」，是这套工具最容易害人的用法。

## 四、第三道关：价格有没有创新极值（代码没替你查）

代码只比 DIF 面积。你必须自己核一遍：

**趋势底背驰**（有意义的那一种）：
- 当前下跌笔的最低点 **低于** 上一段下跌笔的最低点
- 但 DIF 面积 **小于** 上一段
- 这才是「价格新低、力度不新低」的标准背驰

**假的背驰**（必须识别出来）：
- 当前笔的低点 **高于** 上一笔的低点，DIF 也小
- 那叫「回调变浅」，是**上涨中继**，不是底背驰
- 这种情况说成「底背驰」会导致用户在上涨途中以为要跌、或在下跌反弹里以为见底

判断依据：`analyze_chan` 返回的「最近笔向」那一行，形如
`↓10.80→10.20(12根) ↓10.35→10.05(9根)` —— 直接比 `toPrice`。

## 五、背驰段的三种结局（回答时要指明是哪种）

背驰之后不必然反转，只有三种走法：

| 结局 | 特征 | 怎么说 |
|---|---|---|
| **转为趋势反转** | 背驰后回抽进入中枢（一买/一卖成立） | 「反转，可操作」 |
| **转为一个更大中枢** | 背驰后横着磨，形成新中枢 | 「转为震荡，等突破」 |
| **背驰失效（走势延续）** | 背驰后直接放量破前低/前高，力度重新放大 | 「背驰失效，趋势继续」 |

**第 3 种必须提前警告用户**：背驰不是「跌不动了」的保证。
真正的判据是**下一笔的力度重新大于背驰那笔**——那就说明衰竭判断错了。

## 六、标准作业流程

```
第 1 步  analyze_chan(code, period)
         → 拿到 signals[]（label / price / strength）、stats.boxPosition、最近笔向

第 2 步  过第一道关：看 strength 落在哪一档
         · 没有 signals → 「该级别近期无背驰」，到此为止，不要编

第 3 步  过第二道关：看 boxPosition
         · 中枢内 → 直接否决，明确说「中枢内的背驰不算信号」
         · 方向不匹配（下方+顶背驰等）→ 无意义，不要提

第 4 步  过第三道关：核对价格极值
         · 用「最近笔向」比较相邻同向笔的 toPrice
         · 没有创新低/新高 → 不是背驰，是回调变浅 → 改口

第 5 步  需要交叉验证时：compute_indicators 拿 MACD 看 DIF/DEA 是否同步收敛，
         get_kline 看成交量有没有放大（放量破位 = 背驰失效的典型形态）

第 6 步  给分档结论 + 三种结局的应对（见第七部分格式）
```

## 七、给结论的固定格式

```
背驰判定：600000 · 日线

一、信号
  2026-11-12 底背驰，价位 10.05，strength 0.62 → 强档

二、三道关
  ① 力度：0.62，落在「强」档（0.55~0.75）
  ② 位置：中枢下方（ZG 10.35 / ZD 10.02）→ 方向匹配，通过
  ③ 极值：本笔低点 10.05 < 上一段低点 10.20 → 创了新低，通过

三、结论
  标准趋势底背驰，力度强。但背驰 ≠ 买点：
  还需一买成立（回抽站回 ZD 10.02 之上）。

四、三种结局怎么办
  · 反抽站上 10.02 并在其上止跌 → 一买成立，可进场，止损 10.01（新低再让 0.3%）
  · 在 10.02 下方横着磨出新中枢 → 转震荡，观察，不进场
  · 直接放量跌破 10.05 → 背驰失效，趋势延续，**不许在这里抄底**
```

**不成立时的格式**（同样常见）：

```
背驰判定：600000 · 日线

结论：当前没有可用的背驰信号。

原因：
  · 位置：中枢内（ZG 10.62 / ZD 10.20），价格 10.41
  · 该级别最近一次底背驰出现在 10.05，但当时价格已在中枢下方……
  · 更关键：现在处于中枢内部，内部背驰一律不算信号

什么情况下会变：
  · 跌破 ZD 10.20 后出现 strength > 0.35 的底背驰，且创新低 → 再看一买
  · 站上 ZG 10.62 后出现顶背驰 → 才是减仓理由
```

## 八、必须避免的七件事

1. **不要把 `strength 0.15 出头` 说成「背驰强烈」。** 0.15 就是刚过阈值。
2. **不要在中枢内给背驰结论。** 中枢内的背驰一律否决，这是本 skill 存在的理由之一。
3. **不要只报 strength 不报位置。** 缺位置的分档没有操作意义。
4. **不要忽略价格极值。** 代码没查这一条，你不查就等于放过了一半的假背驰。
5. **不要说「背驰所以见底」。** 见底要一买结构确认，背驰只是必要条件。
6. **不要说「背驰了所以不会跌破」。** 背驰失效是最常见的结局之一，必须提。
7. **不要跨级别混用 strength。** 周线的 0.40 和 60 分的 0.40 不是一回事——
   必须带上周期（「日线 strength 0.62」而不是「strength 0.62」）。

## 九、几个典型回答

**问：日线底背驰了，能抄底吗？**
> 力度 strength 0.62，是强的。但两个问题：
> 一是价格还在中枢 10.02~10.35 的下方 10.05，没回到中枢里，
>   一买的第三个条件（回抽回中枢）没满足；
> 二是背驰只说明这一段跌得比上段轻，不代表不再跌。
> 所以现在是「背驰成立、买点不成立」。等它站回 10.02 之上再说。

**问：这个背驰是不是很弱？**
> strength 0.21，刚好过 0.15 的成立线——确实是弱档。
> 而且它在 60 分中枢内部，位置这一关就没过。
> 这种情况在震荡里一天能出三四个，没有参考价值。

**问：背驰之后又跌了，是不是缠论没用？**
> 不是缠论没用，是背驰失效了——这是正常结局之一。
> 判据很明确：背驰之后那一笔的力度如果重新大于背驰那笔（MACD 面积放大），
> 就说明衰减判断错了，走势延续。
> 所以背驰从来不能单独当买入信号，它只是「这里值得盯」。
