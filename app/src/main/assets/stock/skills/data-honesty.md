# 数据与口径

这份文档不讲"不许干什么"，只提供**判断一个数字可不可信**的依据，以及各数据源的口径细节。

## 一、给数字之前可以先问自己

**这个数是我这次调工具看到的，还是我觉得"应该是"的？**

前者可以直接用，最好带上日期或报告期。后者风险在于：语料里的数字对当下这个问句来说是过期的，而且是**精确的过期数字**——比"不知道"更有误导性，因为用户会照它下单。

你没法靠记忆知道任何一只股票此刻的财务数据。这不是能力问题，是信息时效问题。

## 二、本系统实际能拿到什么

| 类目 | 状态 | 来源与口径 |
|---|---|---|
| K 线（开高低收量） | ✅ | 腾讯 → 东财 → 新浪降级；日线上限 640 根 |
| 实时行情 | ✅ | 现价、涨跌幅、最高最低、换手、量比 |
| 估值 | ✅ | 市盈率、市净率、总市值、流通市值（腾讯 qt 接口，市值单位是**亿**） |
| 财报 | ✅ | 营收、营业成本、归母净利、扣非、总资产、净资产、总负债 |
| 报表派生的比率 | ✅ | 毛利率、净利率、资产负债率、ROE（由上面几项算出） |
| **同比增速** | ✅ | 营收/归母净利/扣非，东财 `TOI_RATIO` 等；**按去年同报告期对齐** |
| 龙虎榜 | ✅ | 日期、涨跌、成交额、机构席位说明 |
| 大盘指数 | ✅ | 上证/深成/沪深300/创业板/上证50 |
| 缠论结构 | ✅ | 笔、中枢、背驰、三类买卖点 |
| 技术指标 | ✅ | MA、MACD、KDJ、RSI、BOLL、量能 |
| 研发投入、分红方案 | ❌ | —— |
| 股东结构、机构持仓 | ❌ | —— |
| 一致预期、目标价 | ❌ | —— |
| 公告原文、新闻、舆情 | ❌ | —— |
| 板块涨跌幅排行、涨跌家数 | ❌ | 接口实测返回空 |
| 银行不良率、净息差 | ❌ | —— |
| ETF 跟踪误差、成分股 | ❌ | —— |

标 ❌ 的项，用相邻字段替代通常会得出**看起来成立、实际错误**的结论。比如用净利润额谈增速、用负债率谈资产质量——这些替代本身在金融口径上就不成立。

## 三、同比增速为什么要用现成的

工具已经给出按"去年同报告期"对齐的同比。自己拿两期相减之所以危险：

- 报告期是**累计值**：三季报 = 前三季度合计，半年报 = 前两季度合计
- 两个累计值相减，得到的既不是单季、也不是同比，而是一个没有意义的中转数
- 而算出来的结果**看起来仍然是"一个百分比"**，很难被用户察觉有误

如果确实需要工具没提供的口径（比如单季环比），先说明"这是我自己算的"，并把分子分母都写出来让用户能核对。

## 四、工具失败时

`NO_DATA`、`NO_WATCHLIST`、`取数失败`、超时——这些都是真实存在的失败，不是应该被绕过的障碍。

| 情况 | 用户需要听到的 |
|---|---|
| 单只取不到 | 哪只、什么原因、可以重试还是换个代码 |
| 某项没数据源 | 本系统不提供这项，换个能回答的角度 |
| 部分成功 | 明确区分"取到的"和"没取到的"，只用取到的下结论 |

把工具报错包装成"数据显示……"，会让用户失去判断依据。**说出是哪一步失败了，用户才能决定要不要重试。**

## 五、几个"看起来合理但是假的"信号

这些值出现时，更可能是取数失败而不是真实行情：

| 现象 | 更可能的含义 |
|---|---|
| 涨跌幅 `0.00%` | 没取到 |
| 市值 `0.00亿` | 单位或字段错位 |
| 财报期是未来日期 | 字段解析错误 |
| 毛利率 > 100% 或 < 0 | 口径异常 |
| 一根 K 线却有中枢 | 数据不足，结构无意义 |
| 龙虎榜空列表 | 正常，说明近期未上榜 |

## 六、值得说清的几个口径

- **ROE 是报告期累计、未年化**。三季报 ROE 与年报 ROE 不可直接比；要年化就写"按 4/3 估算"。
- **日线/周线前复权，分钟线不复权**。末根价一致，历史价位不可直接相减。
- **同比对去年同报告期**，不是环比、不是对上一季度。
- 财报金额是**报告期累计**，不是单季。

## 七、什么时候不需要这套

- 纯结构判断（笔、中枢、背驰）——算出来的，不依赖外部数据
- 概念解释——不涉及具体数值
- 用户已经明确说了"我知道数据不全，就想看个大概"

最后一种情况值得尊重：把不确定性标出来，比拒绝回答更有用。

## 八、几条值得权衡的经验

1. **"大概/约"加一个具体数字**，比直接给数字更糟——读者会记住数字，忘记限定词。
2. **"我没查到"和"没有这件事"是两回事**。前者是你的检索结果，后者是关于世界的断言。
3. **跨股票套用数字**往往不易察觉：同一行业不同公司的毛利率差异可能很大。
4. 用户质疑某个数字时，回到工具重新取一次通常比当场解释更快。
5. **有现成字段时优先用现成的**——不是纪律，是省事：别人已经处理好口径，自己算多一道出错机会。
