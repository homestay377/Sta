# 多级别联立

单一级别的买卖点，**只有放到上一级别里看才有意义**。
同一个「日线三买」，在周线上涨里是加仓点，在周线下跌里只是反弹的头部。

这个 skill 的唯一目的：**让结论带上级别，并且不让小级别信号冒充大级别机会。**

## 一、级别怎么排

从大到小固定这个顺序，**不要跳级**：

```
周K (week)  →  日K (day)  →  60分钟 (m60)  →  30分钟 (m30)
   定方向         定结构          定买点           定时机
```

规则：

- **相邻级别是 4~6 倍关系**。周线 1 根 ≈ 日线 5 根，日线 1 根 ≈ 60 分 4 根。
- 只比较**相邻两级**（周↔日、日↔60分）。跨级比较（周线 vs 5 分钟）
  没有操作意义，直接拒绝。
- 用户没说级别时，默认跑 **周 → 日 → 60分** 三级。

## 二、每级只提取三件事

跑完 `analyze_chan` 后，**每级只留三个字段**，其他全部忽略：

| 字段 | 从哪来 | 怎么读 |
|---|---|---|
| 方向 | 最近 2~3 笔的走向 | 连续向上笔 = 涨；连续向下笔 = 跌；交替 = 震荡 |
| 位置 | `stats.boxPosition` | 中枢上方 / 中枢下方 / 中枢内 |
| 信号 | `points`（三类买卖点） | 有就是有，没有就是没有，**不许推测** |

不要复述 `analyze_chan` 返回的全部文本——那是给模型看的原始数据，
用户要的是结论。

## 三、级别关系的四种组合（这是核心判定表）

把「大级别方向」和「小级别状态」交叉，只有四种情况：

| 大级别 | 小级别 | 含义 | 该怎么说 |
|---|---|---|---|
| **涨** | 回抽到中枢下沿不破 | 上涨中的回调买点 | 「大级别向上，小级别回调到位，这是买点」 |
| **涨** | 出三买 | 上涨延续，最强形态 | 「两级共振，可加仓」 |
| **跌** | 出三买/底背驰 | **下跌中的反弹** | 「只是反弹，不是反转，别当买点」 |
| **震荡** | 任意信号 | 级别不够 | 「大级别没方向，小级别信号只能做短线」 |

**第三行是最容易出错的**，重点记住。

### 为什么要警惕「大级别跌 + 小级别买点」

周线在下跌趋势里，日线出三买，价格确实能涨三五天——
但那是**反弹**，涨完还要跌。把它说成"买点"，用户会重仓进去然后被套。

正确的说法：

> 日线三买成立（价位 10.68），但周线还在下跌笔里，中枢在 12.40 上方压着。
> 这是**反弹级别**的买点，不是趋势买点。仓位控制在试仓，目标只看上一交易日高点 11.05，
> 不看到周线上穿 12.40 之前，不加仓。

## 四、标准作业流程

```
第 1 步  直接调 analyze_levels(code)
         → 一次拿回「方向 / 中枢位置 / 信号」对照表 + 级别冲突结论

         不要自己连调三次 analyze_chan。理由：
           · 跨周期必须串行，你自己拼很容易顺序错、级别串
           · 每级返回都是长文本，读三遍既费上下文又容易读串
           · "级别冲突"由工具算，比你目测可靠
         需要自定义级别时才传 periods，例如 ["day","m30"]。
         跨级比较（周K 对 5 分钟）没有操作意义，不要这么传。

第 2 步  看它返回的表：

         级别     方向   位置       主板/中框             信号
         周K      下跌   中枢上方   ZG 12.40 / ZD 11.80   无
         日K      上涨   中枢上方   ZG 10.35 / ZD 10.02   三买 10.68
         60分钟   上涨   中枢内     ZG 10.60 / ZD 10.30   无

第 3 步  如果工具已给出「级别冲突」，直接采用它的结论，不要自己推翻。
         如果它只给了「级别一致」或「无明确冲突」，你再用第三部分那张表
         判一次相邻两级的关系。

第 4 步  只在需要更细的确认时才补调 analyze_chan（单级别）。
         例如 60分 没给信号，你想看它最近的笔怎么走。

第 5 步  给结论。必须写清：
           · 哪一级是什么结论
           · 两级是什么关系（共振 / 压制 / 反弹）
           · 操作建议落在**最小级别的买点**上，但仓位由**最大级别的方向**决定

第 6 步  annotate_chart 把关键价位画到图上（止损、目标、中枢上下沿）

第 7 步  如果用户问的是「已经持有的仓位怎么办」，多级别结论要接着
         交给 `chan-position` skill 落地成加减仓动作；
         本 skill 只回答「各级别是什么状态」，不回答「卖多少」。
```

## 五、给结论的固定格式

```
级别判断（周 → 日 → 60分）：

  周K　下跌　中枢上方（ZG 12.40 / ZD 11.80）　无信号
  日K　上涨　中枢上方（ZG 10.35 / ZD 10.02）　三买 10.68
  60分 上涨　中枢内　　　　　　　　　　　　　无信号

关系：周线压制 + 日线走强 = 反弹级别，不是趋势反转。

操作：
  · 信号来自日线三买（10.68），但周线在下跌笔里
  · 仓位：试仓（不超过 3 成），不重仓
  · 止损：10.32（日线 ZG 再让 0.3%）
  · 目标：11.05（前一交易日高点），不看 12.40
  · 转折条件：周线上穿 12.40 且回抽不破 → 升级为趋势买点，可加仓

60分：还在中枢内，没有给出更精确的入场点。等它突破中枢上沿再看。
```

### 三级共振才敢重仓

只有**周、日、60分 三级方向一致**时才说「可以重仓/加仓」。
任何一级相反，仓位建议必须对应降级：

| 级别一致性 | 仓位建议 |
|---|---|
| 三级同向 | 正常仓位 |
| 两级同向、一级相反 | 试仓（不超 3 成） |
| 大级别相反 | 只说「反弹」，建议不参与或极小仓 |

## 六、必须避免的六件事

1. **多级别判断一律先调 `analyze_levels`。** 它内部已经串行取数；
   你自己并发调 `analyze_chan` 会让返回值与级别对不上。
2. **不要跨级比较。** 周线和 5 分钟没有可比性，直接说「这两个级别不能直接比」。
3. **不要把小级别信号说成大级别机会。** 这是本 skill 存在的全部理由。
4. **不要只报一级。** 用户问「多级别」就必须至少两级，报一级等于没做。
5. **不要在数据不足时硬凑。** 周线只有十几根 K 线时，直接说
   「周线数据不足，无法判断级别方向」——不要用日线的方向去顶替。
6. **不要忽略连接关系。** 说结论时必须写清哪一级推导出哪个结论，
   不许出现「综合来看…」这种没有出处的判断。

## 七、几个典型回答

**问：帮我多级别看一下**
> 调 analyze_levels 后得到：周K 下跌（中枢 11.80~12.40，价在上方）→ 日K 上涨
> （中枢 10.02~10.35，三买 10.68）→ 60分 中枢内震荡。
> 工具标注「级别冲突：周K下跌，但日K上涨」——所以日线三买属于反弹级别。
> 试仓，止损 10.32，目标先看 11.05。

**问：日线都三买了，为什么不能重仓？**
> 因为周线还在下跌笔里。日线三买只说明**这一级**走强，
> 周线中枢 12.40 还在上方压着——日线涨到那儿会先撞压力。
> 三级方向不一致时重仓，等于用大级别的风险去赌小级别的正确性。

**问：60分和日线方向不一致，听谁的？**
> 听日线的。级别越大越有效，60分只是日线内部的一笔。
> 具体做法：用日线定方向（做多还是不做），用 60分定入场时机（现在买还是等回抽）。

**问：周线数据不够怎么办？**
> 周线只有 18 根，中枢还没形成，无法判断级别方向。
> 这种情况我只能给日线一级的结论，并明确标注「缺少周线确认，信号可靠性下降」。
